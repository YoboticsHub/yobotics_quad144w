2.4 Simulation Debugging¶

LCM Monitoring¶

bash scripts/monitor_lcm.sh --no-gui
bash scripts/monitor_lcm.sh
bash scripts/launch_lcm_spy.sh

If no terminal messages appear, check the channel names in config_sim.yaml, the LCM Python module, and local multicast configuration.

Log Viewing¶

Simulation writes controller logs to log/robot_log.txt by default. RL CSV paths are defined by each policy block's log_file_path.

python3 scripts/data_viewer.py
python3 scripts/motor_trace_viewer.py log/motor_trace.csv

Focus on comparing desired and actual joint position, velocity, and torque. Wheel-joint variables include wheel in their names.

Common Issues¶

Symptom Check
Scene file does not exist Whether simulation.mujoco.xml_path points to resources_sim/
Controller cannot find shared libraries Use the startup script; do not bypass the wrapper and run .bin directly
Model loading fails actor/encoder paths, ONNX Runtime, and model input/output dimensions
Robot suddenly diverges Joint order, default angles, PD, action scale, and control period
Mode cannot switch gamepad.device_type, input device, and mode_sequence

Debug Loop¶

  1. Record a reproducible mode, velocity command, and configuration file.
  2. Use LCM monitoring to confirm input, state, and output channels are continuous.
  3. Use log viewers to compare desired and actual values and locate the affected joint.
  4. Return to DAMP and change only one parameter at a time.
  5. Repeat the same operation and compare logs before and after the change.

Symptom to Action¶

Symptom Immediate action Next evidence
Model diverges rapidly Switch back to a safe mode and stop Joint target, actual value, and PD before divergence
One wheel direction is wrong Stop wheel commands supplement index and XML axis direction
State frequency is normal but motion stutters Check command frequency Inference time, CPU, and send loop
Only external algorithm mode is abnormal Retest with low-amplitude wave Separate model issues from DEVELOPMENT link issues
All modes are abnormal Check lower-level state and model XML, joint order, control period, and channel interference

When locating external-algorithm issues, continue with Communication Architecture and ONNX Walking Example.

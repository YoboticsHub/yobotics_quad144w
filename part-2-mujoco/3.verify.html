2.3 Model and Mode Verification¶

Startup Checks¶

  1. The model does not penetrate the ground or shake violently.
  2. The initial state is DAMP, and mode switching follows gamepad.mode_sequence.
  3. The terminal has no ONNX path, input dimension, or shared-library errors.
  4. Joint state, command, and IMU channels continue updating in LCM.

Policy Configuration¶

Mode Configuration block Main model directory
RL_WALK rl_walk actor_model/y20w_v3/terrain/
RL_HIGHSPEED rl_highspeed actor_model/y20w_s2/vel/
RL_CLIMB rl_climb actor_model/high_s2/
RL_STAND rl_stand actor_model/stand/

Y20W currently uses dof_dim: 16, joint_dim: 12, and wheel_dim: 4. When replacing a model, check obs_dim, the action count, observation history, default joint positions, and action scale. Do not replace only the ONNX file.

Recommended Verification Order¶

Switch from DAMP to RECOVERY_STAND. After the posture is stable, test RL_STAND and low-speed RL_WALK. High-speed and climbing policies should be validated separately on suitable terrain and within safety limits.

Staged Acceptance¶

Stage Operation Pass condition
Initial Stay in DAMP Model is stable, state is continuous, no model errors
Stand recovery Enter RECOVERY_STAND Four legs move in the correct direction and posture does not diverge continuously
Standing policy Enter RL_STAND Stable at zero velocity and exits smoothly
Low-speed walking Send a small forward command Velocity direction is correct and wheel-legs are not mismatched
Single-axis test Test lateral and yaw separately Returns to stable state after command removal
Abnormal exit Switch back to a safe mode during motion Commands clear to zero and the model stops moving

Change only one variable at each stage. If a stage fails, save the configuration and logs, return to the previous mode, and do not mask the problem by increasing gains or speed.

Model Replacement Checks¶

  • The actor and encoder files come from the same export version.
  • obs_dim, dof_dim, joint_dim, and wheel_dim match the deployment code.
  • Default joint positions and action order use the Y20W 16D layout.
  • Observation normalization, action scaling, and control period match training.
  • The model is stable with zero command, small command, and mode re-entry.

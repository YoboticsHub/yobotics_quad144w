# 4.3 运动控制

`SportClient` 保留以下公共方法：

```cpp
SportClient client;
client.EnableLCMControl();
client.RecoveryStand();
client.RLWalk();
client.Move(0.2f, 0.0f, 0.0f);
client.BodyHeight(0.0f);
client.Euler(0.0f, 0.0f);
```

## API 编号

| 方法/模式 | API |
| --- | --- |
| `Passive()` | 1000 |
| `Damp()` | 1001 |
| `RLWalk()` | 1002 |
| `Development()` | 1005 |
| `RecoveryStand()` | 1006 |
| `StandDown()` | 1007 |

## 方法语义

| 方法 | 行为 |
| --- | --- |
| `EnableLCMControl()` | 设置 `rc_enable=1` 并发布，使控制器接收 LCM 高层输入 |
| `DisableLCMControl()` | 设置 `rc_enable=0` 并发布 |
| `Passive()` / `Damp()` | 切换模式并清零速度、高度和姿态字段 |
| `RecoveryStand()` / `StandDown()` | 切换模式并清零运动字段 |
| `RLWalk()` | 设置 RL 行走 API，保留当前运动字段 |
| `Development()` | 设置 DEVELOPMENT API，保留当前运动字段 |
| `Move(vx, vy, vyaw)` | 更新三个速度分量并立即发布 |
| `BodyHeight(h)` | 把高度限制到 `[-1.0, 0.2]` 后发布 |
| `Euler(roll, pitch)` | 分别限制到 `[-0.5, 0.5]` 后发布 |

所有公共方法当前返回 `0`，表示命令已提交到 SDK 发布路径，不表示控制器已经切换成功。应用应通过状态通道确认结果。

运动程序应周期发送 `EnableLCMControl()`、当前模式和运动命令。只发送一次的命令可能被遥控器输入或超时逻辑覆盖。

```cpp
#include <chrono>
#include <thread>
#include "robot/sport/sport_client.hpp"

using yobotics::robot::SportClient;

SportClient client;
client.EnableLCMControl();
client.RecoveryStand();
std::this_thread::sleep_for(std::chrono::seconds(2));

for (int i = 0; i < 100; ++i) {
  client.EnableLCMControl();
  client.RLWalk();
  client.Move(0.1f, 0.0f, 0.0f);
  std::this_thread::sleep_for(std::chrono::milliseconds(40));
}

client.Move(0.0f, 0.0f, 0.0f);
client.Damp();
client.DisableLCMControl();
```

示例周期约为 25 Hz，仅用于展示持续发送方式；具体业务频率应结合控制器、网络和应用需求验证。

## 键盘示例

```bash
yobotics_sdk/build/yobot_sport_client
```

![运动控制按键](../assets/sdk/sport-client-controls.png)

方向键控制前后和转向，`H/J` 横移，`Q/A/Z` 调整或复位高度，`W/S/X` 调整或复位横滚，`E/D/C` 调整或复位俯仰，`V` 退出。

!!! danger
    SDK 会向真实控制器发布运动命令。连接实机前先在仿真中运行同一示例，并将速度命令保持在保守范围。

## 验收与停止

- 先运行状态客户端，再运行运动客户端；
- 每次模式调用后通过状态确认，而不是只看返回值；
- 松开按键或结束业务循环时主动发送零速度；
- 退出前切回 `DAMP`，最后禁用 LCM 控制；
- 多个 SDK 客户端不要同时发布到同一控制通道。

# 1.3 开发包目录

```text
yobotics_quad144w/
├── bin/、lib/                 # x86_64 控制器入口与动态库
├── bin_rk3588/、lib_rk3588/ # RK3588/aarch64 控制器入口与动态库
├── actor_model/             # RL actor/encoder 模型
├── resources/               # 实机 Viewer 使用的模型资源
├── resources_sim/           # MuJoCo 仿真资源
├── mujoco_sim/              # 仿真程序
├── scripts/                 # 启动、网络、监控和日志工具
├── lcm-types/               # LCM 定义及生成代码
├── external_algorithms/     # DEVELOPMENT 模式示例
├── yobotics_sdk/            # C++ SDK 与 HTTP 示例
├── WebRTC_server/           # 视频和 DataChannel 服务
├── config.yaml              # 实机配置
└── config_sim.yaml          # 仿真配置
```

## 两套资源目录

- `resources_sim/robots/quad144w/` 用于 MuJoCo 仿真。
- `resources/robots/quad144w/` 用于实机状态 Viewer 和实机安全检查。

两套目录都包含 Y20W 的 XML、URDF 和 mesh，但服务于不同运行场景。修改路径时必须同步检查配置文件中的 `simulation.mujoco.xml_path` 和 `safety_checker.urdf_path`。

## 二进制开发包

本仓库按二次开发包使用，控制器由 `bin/ybt_ctrl` 或 `bin_rk3588/ybt_ctrl` 启动。不要假定仓库包含控制器源码或顶层 CMake 工程；可编译部分是 `yobotics_sdk/` 中的客户 SDK。

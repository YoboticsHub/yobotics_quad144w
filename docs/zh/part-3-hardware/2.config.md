# 3.2 配置实机参数

实机使用根目录 `config.yaml`。至少核对以下配置。

## 电机通信

```yaml
motor_communication:
  type: "spi"
  board: "rk3588"
  spi_device0: "/dev/spidev2.0"
  spi_device1: "/dev/spidev2.1"
```

`board` 支持 `rk3588` 或 `upboard`，用于选择对应的 SPI 帧与转换逻辑；它与当前 CPU 架构不是同一个概念。设备节点必须以现场系统为准。

## IMU

```yaml
imu:
  type: "lord"
  port_base: "/dev/ttyUSB"
  port_number: 0
```

`lord` 使用 `port_base + port_number`，`hipnuc` 使用配置的完整串口路径。确认设备权限、串口未被其他进程占用。

## 电源与时钟同步

- `power_reader` 控制电源/BMS 数据读取，检查 CAN 接口或对应设备。
- `tsync_cdc` 控制时间同步 CDC 串口，默认设备为 `/dev/ttyACM2`。

现场没有对应硬件时，应根据交付配置明确关闭相关功能，而不是保留错误设备号反复启动。

## 通道和资源

```yaml
development:
  robot_id: "Y20W"
  state_channel: "Y20W_development_state"
  command_channel: "Y20W_development_command"
gamepad:
  lcm_control_channel: "QUAD_ROBOT_CONTROL_Y20W"
  lcm_state_channel: "QUAD_ROBOT_STATE_Y20W"
safety_checker:
  urdf_path: "resources/robots/quad144w/urdf/sduog144_V2_s.urdf"
```

## 策略与控制周期

`rl_walk` 当前关键参数如下：

| 字段 | 当前值 | 作用 |
| --- | ---: | --- |
| `obs_dim` | `57` | 策略观测维度 |
| `dof_dim` | `16` | 轮足总自由度 |
| `joint_dim` / `wheel_dim` | `12` / `4` | 主关节和 supplement 分组 |
| `control_dt` | `0.02 s` | 策略控制周期 |
| `decimation` | `10` | 控制降采样 |
| `action_scale` | `0.25` | 腿关节动作缩放 |
| `action_scale_wheel` | `10` | wheel 动作缩放 |
| `clip_obs` / `clip_action` | `100` / `100` | 观测和动作裁剪 |
| `tau_limit` | `200` | 配置的扭矩限制 |

模型文件、默认 16 维姿态、Kp/Kd、缩放和控制周期必须成套修改。只替换 ONNX 文件可能让维度正确但语义错误。

## 手柄与上层控制

| 字段 | 当前值 | 说明 |
| --- | --- | --- |
| `device_type` | `hybrid` | 支持配置中的混合输入方式 |
| `joystick_device` | `/dev/input/js0` | Linux 手柄设备 |
| `deadzone` | `0.1` | 摇杆死区 |
| 前进/后退/横向上限 | `1.0 m/s` | 当前配置速度上限 |
| `speed_yaw_max` | `1.3 rad/s` | 偏航角速度上限 |

首次实机测试应使用更保守的独立配置，先校准手柄，再验证模式按键和零位，最后逐步开放速度。

## 安全检查

`enable_safety_check` 是总开关；各 `enable_*_check` 决定具体检查是否启用。当前配置并非所有检查都开启，不能只看到总开关为 `true` 就认为姿态、关节位置、速度、扭矩和硬件丢失均受保护。

| 配置 | 当前值 | 说明 |
| --- | --- | --- |
| `enable_leg_cartesian_velocity_check` | `true` | 当前启用的腿部笛卡尔速度检查 |
| `enable_orientation_check` | `false` | 姿态阈值当前不触发保护 |
| `enable_joint_*_check` | `false` | 关节位置、速度、扭矩检查当前关闭 |
| `enable_hardware_loss_check` | `false` | 硬件丢失保护当前关闭 |
| `safety_margin_factor` | `0.95` | URDF 限制的安全裕度系数 |
| `max_roll_deg` / `max_pitch_deg` | `30` / `50` | 姿态检查启用后使用 |

启用或关闭任何安全项前，应在支架环境验证触发条件、状态机结果和恢复方式。不要仅为消除日志关闭保护。

## 配置验收

```bash
test -e /dev/spidev2.0
test -e /dev/spidev2.1
test -e /dev/ttyUSB0
test -e /dev/ttyACM2
test -f resources/robots/quad144w/urdf/sduog144_V2_s.urdf
```

设备名仅用于核对当前默认配置，现场系统应以实际枚举结果为准。缺少可选硬件时，要明确关闭对应读取器并记录原因。

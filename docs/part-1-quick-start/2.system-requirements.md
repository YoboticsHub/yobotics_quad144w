# 1.2 系统与环境

## 支持平台

| 场景 | 架构 | 控制器与库 |
| --- | --- | --- |
| 开发机/仿真 | x86_64 | `bin/`、`lib/` |
| Y20W RK3588 | aarch64/arm64 | `bin_rk3588/`、`lib_rk3588/` |

建议使用带图形桌面的 Ubuntu 运行 MuJoCo 和日志 Viewer。无图形环境可使用仿真的 `--headless` 参数。

## 自动安装

在项目根目录执行：

```bash
bash scripts/setup_conda_env.sh
conda activate quad_controller
```

脚本准备 Python 3.8、MuJoCo、NumPy、PyYAML、ONNX Runtime 和 Python LCM。系统侧还需要 `liblcm-dev` 与常用构建工具。

## 手动检查

```bash
python3 -c "import mujoco, numpy, yaml, onnxruntime; print('Python dependencies OK')"
python3 -c "import lcm; print('Python LCM OK')"
lcm-gen --version
```

仅修复 Conda 环境中的 Python LCM 时运行：

```bash
bash scripts/install_python_lcm.sh
```

## 安装 Conda

没有 Conda 时可从 Anaconda 或 Miniconda 获取 Linux 安装程序。RK3588 使用 ARM64 安装包，x86_64 开发机使用 x86 安装包。

## 环境验收

| 检查 | 成功标志 | 失败时处理 |
| --- | --- | --- |
| `conda activate quad_controller` | 提示符显示目标环境 | 重新执行安装脚本并确认 Conda 初始化 |
| Python 依赖导入 | 输出 `Python dependencies OK` | 确认当前 `python3` 来自目标环境 |
| `import lcm` | 输出 `Python LCM OK` | 运行 `install_python_lcm.sh` |
| `lcm-gen --version` | 返回版本信息 | 安装系统 LCM 开发包 |
| MuJoCo 图形环境 | 能创建窗口 | 检查显卡驱动、DISPLAY 和远程桌面 |

无图形服务器可以运行 headless 仿真和 LCM 工具，但不能使用 MuJoCo Viewer、硬件 Viewer 和交互式绘图窗口。

## 常见环境冲突

- `pip` 与 `python3` 来自不同环境：使用 `python3 -m pip` 安装。
- 系统 LCM 与 Conda Python 不匹配：先确认 `which python3` 和实际导入位置。
- 远程 SSH 没有 DISPLAY：使用 `--headless`，或配置图形转发。
- RK3588 上误用 x86 安装包：重新选择 ARM64 Conda 和对应库目录。

# 3.5 Viewers and Logs

## Hardware Posture Viewer

Run on a graphical workstation that can access the robot's LCM multicast:

```bash
bash scripts/start_hardware_viewer.sh
```

By default it loads `resources/robots/quad144w/scene_terrain.xml` and subscribes to `Y20W_QUAD_JOINT_STATE` and `QUAD_ROBOT_STATE_Y20W`. Custom options:

```bash
bash scripts/start_hardware_viewer.sh --help
```

The Viewer only replays state and does not send control commands to the robot.

Common options:

| Option | Default | Purpose |
| --- | --- | --- |
| `--xml` | `resources/robots/quad144w/scene_terrain.xml` | Viewer model |
| `--lcm-url` | Project multicast URL | State source |
| `--viewer-hz` | `60` | Target display update frequency |

```bash
bash scripts/start_hardware_viewer.sh   --lcm-url 'udpm://239.255.76.67:7667?ttl=255'   --viewer-hz 60
```

If posture is correct but joints do not move in the Viewer, check the raw joint channel. If joints are correct but body posture is wrong, check high-level state and the Viewer free-joint setup.

## CSV Viewing

```bash
python3 scripts/data_viewer.py
python3 scripts/motor_trace_viewer.py <csv-file>
```

`data_viewer.py` is suitable for browsing RL log variables. `motor_trace_viewer.py` is suitable for comparing desired and actual motor values. Both recognize `hip`, `thigh`, `calf`, and `wheel`.

When viewing logs, compare desired/actual position, velocity, and torque for the same joint first, then compare symmetry across four legs. If CSV column names do not match tool expectations, inspect the header first; do not treat an empty plot as a zero state.

## Gamepad Calibration

```bash
python3 scripts/calibrate_gamepad.py
```

Follow the program prompts for buttons and sticks, then verify the output mapping and write it into the `gamepad` section of `config.yaml`. Initial hardware tests should reduce speed limits and verify the dead zone.

## Tool Acceptance

- The Viewer refreshes continuously and does not pretend stale state is live after disconnection.
- CSV tools recognize the time axis and target/actual columns.
- Gamepad axes stay inside the dead zone when untouched.
- All mode buttons are verified one by one in MuJoCo first.
- The Viewer and plotting tools are for observation only; safety decisions still rely on the controller and onsite state.

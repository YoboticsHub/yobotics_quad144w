# 4.1 SDK Overview

`yobotics_sdk/` provides a C++11 static library and three example programs for high-level motion control, state reading, and an HTTP service. The SDK communicates through LCM and does not operate SPI or motor drivers directly.

## Directory

```text
yobotics_sdk/
├── include/                 # SDK headers and embedded LCM types
├── example/
│   ├── sport_client.cpp     # keyboard motion control
│   ├── robot_state_client.cpp
│   └── http_server.cpp
├── lib/                     # generated static library
└── CMakeLists.txt
```

## Main Channels

| Channel | Direction | Message |
| --- | --- | --- |
| `QUAD_ROBOT_CONTROL_Y20W` | SDK -> controller | `sport_client_cmd_t` |
| `QUAD_ROBOT_STATE_Y20W` | controller -> SDK | `sport_client_state_t` |
| `Y20W_QUAD_JOINT_STATE` | controller -> SDK | `quad_joint_state_t` |
| `Y20W_QUAD_JOINT_COMMAND` | controller -> SDK | `quad_joint_command_t` |
| `Y20W_development_state` | controller -> development side | `development_state_t` |
| `Y20W_development_command` | development side -> controller | `development_command_t` |

## Interface Boundary

`SportClient` is suitable for switching modes and sending velocity/posture commands. If you need to generate 16D joint targets directly, use the DEVELOPMENT protocol and the external-algorithm framework in Part 5.

## Call Lifecycle

```text
Create SportClient
  -> enable LCM control
  -> periodically send current mode
  -> send velocity/posture in motion-capable modes
  -> zero velocity
  -> switch DAMP/StandDown
  -> disable LCM control
```

SDK methods update the same command object and publish immediately. Mode methods set `api`; some modes also clear motion fields. `Move()`, `BodyHeight()`, and `Euler()` update their own fields. Business programs should therefore maintain the current mode and complete command state explicitly.

## Choosing an Interface

| Need | Recommended interface |
| --- | --- |
| Switch modes and send velocity | `SportClient` |
| View battery, posture, and mode | `sport_client_state_t` |
| View 16 axes, temperature, and faults | `quad_joint_state_t` |
| Send joint-level algorithm targets | DEVELOPMENT external algorithm |
| Provide LAN REST API | `yobot_http_server` |

# 4.4 State Reading

Run the state example:

```bash
yobotics_sdk/build/yobot_robot_state_client
```

You can also pass the LCM URL as the first argument:

```bash
yobotics_sdk/build/yobot_robot_state_client   'udpm://239.255.76.67:7667?ttl=255'
```

The example reads three groups of data:

- `sport_client_state_t`: battery, posture, velocity, height, mode, and faults.
- `quad_joint_state_t`: positions, velocities, torques, faults, temperatures, and SPI states for 12 leg joints and 4 wheel joints.
- `quad_joint_command_t`: targets, PD values, and feedforward torque for leg and wheel joints.

Wheel joints are in `*_supplement[4]` in the order `LF, RF, LR, RR`. Main arrays contain only `hip, thigh, calf` for each leg.

If high-level state is received but joint state remains zero, check the frequency of `Y20W_QUAD_JOINT_STATE` and `Y20W_QUAD_JOINT_COMMAND`, and confirm that the SDK and controller use the same LCM URL.

## Field Interpretation

| Message | Key fields | Purpose |
| --- | --- | --- |
| `sport_client_state_t` | `power[2]`, `rpy[3]`, `v`, `h`, `state`, `fault` | Application-level robot summary |
| `quad_joint_state_t` | `joint_q/qd/tau` and supplement | Actual 16-axis state |
| `quad_joint_state_t` | `flags[4]`, `spi_driver_status` | Leg-level and driver state |
| `quad_joint_state_t` | `joint_fault/temp` and supplement | 16-axis faults and temperatures |
| `quad_joint_command_t` | `joint_des_*` and supplement | Current controller output targets |

## State Acceptance

- Positions are stable when stationary, and velocity is close to the real stationary state.
- When an allowed joint is moved slowly by hand, the corresponding index changes.
- The four wheels appear only in supplement order LF, RF, LR, RR.
- High-level `state` changes with controller mode switching.
- Fault and temperature fields are not constant or misaligned because of old type decoding.

The state client is an observation tool and does not implement state-timeout protection. Business integrations should record the last receive time and define behavior for stale state.

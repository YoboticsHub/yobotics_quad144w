# 2.1 Simulation Architecture

The MuJoCo process loads the Y20W scene and exchanges joint and IMU data with the controller through LCM. The controller uses the same state machine and policy configuration as hardware, while the motor communication type is changed to `lcm`.

```text
config_sim.yaml
      |
      +--> mujoco_sim.mujoco_simulator
      |       publishes Y20W_QUAD_JOINT_STATE / Y20W_QUAD_IMU_DATA
      |       subscribes Y20W_QUAD_JOINT_COMMAND
      |
      +--> bin/ybt_ctrl
              loads actor_model/ and runs the state machine
```

Key default simulation settings:

```yaml
motor_communication:
  type: "lcm"
simulation:
  enable_mujoco: true
  mujoco:
    xml_path: "resources_sim/robots/quad144w/scene_terrain.xml"
```

Simulation is used to verify model loading, the 16D joint order, action continuity, mode switching, LCM communication, and log output. It cannot replace hardware checks for SPI, IMU, power, or mechanical safety.

## One Control Cycle

1. MuJoCo advances dynamics according to the actuator targets from the previous frame.
2. The simulator publishes 12+4 joint states and virtual IMU data.
3. The controller updates state estimation, the state machine, and the current policy.
4. The controller publishes 12+4 joint commands.
5. MuJoCo receives the commands and enters the next step.

When an external algorithm is enabled, the controller also generates `Y20W_development_state` and uses `Y20W_development_command` as input to the DEVELOPMENT state machine. External algorithms still do not connect directly to MuJoCo.

## What Simulation Can Verify

| Can verify | Still requires hardware |
| --- | --- |
| Model files and dimensions | SPI frames and device nodes |
| Joint names, order, and directions | Motor zero positions, friction, and mechanical assembly |
| State machine and mode switching | Real IMU mounting direction and drift |
| LCM types and channels | Power, BMS, and clock synchronization |
| Observation, action, scaling, and PD trends | Temperature rise, driver faults, and emergency stop |

Passing simulation is required before hardware testing, but it is not a hardware safety conclusion.

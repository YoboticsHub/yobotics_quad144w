3.3 启动控制器¶

架构自动选择¶

run_robot_controller.sh 根据 uname -m 选择运行目录：

系统架构 首选入口 动态库目录
x86_64 bin/ybt_ctrl lib/
aarch64 / arm64 bin_rk3588/ybt_ctrl lib_rk3588/

ARM 目录不存在时脚本才回退到 bin/ 和 lib/。显式传入控制器路径时，以用户指定值为准。

启动命令¶

sudo bash scripts/run_robot_controller.sh --config config.yaml

默认 LCM 网卡为 eth0，现场使用其他网卡时：

sudo bash scripts/run_robot_controller.sh --config config.yaml --iface <网卡名>

也可使用环境变量：

LCM_IFACE=<网卡名> sudo -E bash scripts/run_robot_controller.sh --config config.yaml

包装入口会设置 LD_LIBRARY_PATH，不建议直接执行 ybt_ctrl.bin。

启动输出核对¶

脚本在执行控制器前会打印：系统架构、部署结构、可执行文件、配置文件、库目录和 LCM 网卡。确认这些路径与当前设备一致后再继续。

ARM 平台只有在 bin_rk3588/ 或 lib_rk3588/ 存在时才选择 RK3588 目录，否则回退到通用 bin/ 和 lib/。回退只表示路径选择，不证明其中程序适用于 ARM。

启动成功标志¶

  • 两路 SPI 与 IMU 打开成功；
  • 控制器没有立即退出或持续打印硬件错误；
  • 高层状态和原始关节状态持续更新；
  • 16 个关节数据、温度、故障和驱动状态可读；
  • 初始 DAMP 下机器人没有主动运动。

启动失败¶

现象 优先检查
找不到控制器 脚本打印的架构与 bin* 目录
找不到动态库 对应 lib* 目录和脚本入口
SPI 权限或设备错误 设备节点、板型和 root 权限
IMU 打不开 类型、串口路径、权限和占用进程
本机运行但远端无状态 --iface、多播 URL、路由和防火墙

启动后继续执行 状态检查与停止，不要直接切换运动模式。

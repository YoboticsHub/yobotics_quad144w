4.4 状态读取¶

运行状态示例：

yobotics_sdk/build/yobot_robot_state_client

也可以把 LCM URL 作为第一个参数：

yobotics_sdk/build/yobot_robot_state_client \
  'udpm://239.255.76.67:7667?ttl=255'

示例读取三组数据：

  • sport_client_state_t：电量、姿态、速度、高度、模式和故障。
  • quad_joint_state_t：12 个腿关节和 4 个轮关节的位置、速度、扭矩、故障、温度及 SPI 状态。
  • quad_joint_command_t：腿关节和轮关节的目标值、PD 和前馈扭矩。

轮关节位于 *_supplement[4]，顺序为 LF, RF, LR, RR。主数组只包含每条腿的 hip, thigh, calf。

如果高层状态能收到而关节状态始终为零，检查 Y20W_QUAD_JOINT_STATE 和 Y20W_QUAD_JOINT_COMMAND 的频率及 SDK/控制器是否使用同一 LCM URL。

字段解读¶

消息 重点字段 用途
sport_client_state_t power[2]、rpy[3]、v、h、state、fault 面向应用的机器人摘要
quad_joint_state_t joint_q/qd/tau 与 supplement 16 轴实际状态
quad_joint_state_t flags[4]、spi_driver_status 腿级与驱动状态
quad_joint_state_t joint_fault/temp 与 supplement 16 轴故障和温度
quad_joint_command_t joint_des_* 与 supplement 控制器当前输出目标

状态验收¶

  • 静止时位置稳定，速度接近实际静止状态；
  • 手动缓慢转动允许的关节时，对应索引变化；
  • 四个 wheel 只出现在 supplement 顺序 LF、RF、LR、RR；
  • 控制器模式切换时高层 state 有对应变化；
  • 故障与温度字段不是因为旧类型解码而恒定或错位。

状态客户端是观察工具，不执行状态超时保护。业务集成应记录最后接收时间，并明确状态过期后的行为。

4.1 SDK 概览¶

yobotics_sdk/ 提供 C++11 静态库和三个示例程序，用于高层运动控制、状态读取和 HTTP 服务。SDK 通过 LCM 通信，不直接操作 SPI 或电机驱动。

目录¶

yobotics_sdk/
├── include/                 # SDK 头文件与内嵌 LCM 类型
├── example/
│   ├── sport_client.cpp     # 键盘运动控制
│   ├── robot_state_client.cpp
│   └── http_server.cpp
├── lib/                     # 编译后生成静态库
└── CMakeLists.txt

主要通道¶

通道 方向 消息
QUAD_ROBOT_CONTROL_Y20W SDK -> 控制器 sport_client_cmd_t
QUAD_ROBOT_STATE_Y20W 控制器 -> SDK sport_client_state_t
Y20W_QUAD_JOINT_STATE 控制器 -> SDK quad_joint_state_t
Y20W_QUAD_JOINT_COMMAND 控制器 -> SDK quad_joint_command_t
Y20W_development_state 控制器 -> 开发端 development_state_t
Y20W_development_command 开发端 -> 控制器 development_command_t

接口边界¶

SportClient 适合切换模式和发送速度/姿态命令。需要直接生成 16 维关节目标时，应使用 DEVELOPMENT 协议和第五部分的外部算法框架。

调用生命周期¶

创建 SportClient
  -> 设置 LCM 控制权
  -> 周期发送当前模式
  -> 在允许运动的模式发送速度/姿态
  -> 速度清零
  -> 切换 DAMP/StandDown
  -> 释放 LCM 控制权

SDK 方法更新同一个命令对象并立即发布。模式方法会设置 api，部分模式同时清零运动字段；Move()、BodyHeight() 和 Euler() 则更新各自字段。因此业务程序应明确维护当前模式和完整命令状态。

选择接口¶

需求 推荐接口
切换模式、发送速度 SportClient
查看电量、姿态和模式 sport_client_state_t
查看 16 轴、温度和故障 quad_joint_state_t
发送关节级算法目标 DEVELOPMENT 外部算法
提供局域网 REST 接口 yobot_http_server

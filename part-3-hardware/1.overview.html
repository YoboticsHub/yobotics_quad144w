3.1 实机结构与安全¶

实机控制器读取 IMU 和 SPI 电机状态，运行状态机与策略，再向两路 SPI 设备发送 16 轴命令。SDK、WebRTC 和外部算法通过 LCM 与控制器通信。

遥控器 / SDK / WebRTC       外部算法
          |                    |
          v                    v
       Y20W 控制器 <------ DEVELOPMENT LCM
        |    |    |
       SPI  IMU  状态 LCM
        |
   12 腿关节 + 4 轮关节

运行前必须确认

急停有效、机器人有可靠支撑、轮子离地或区域清空、供电正常、线缆不会卷入轮足、SPI 与 IMU 设备号正确，并且现场人员知道如何立即切回 DAMP 和断电。

实机默认安全检查从 URDF 读取关节限制。不要为了消除报错直接关闭 safety_checker.enable_safety_check；应先定位模型、传感器或参数问题。

实机数据链¶

  1. 两路 SPI 读取 12 个腿关节和 4 个轮关节状态。
  2. IMU 提供姿态、角速度和加速度。
  3. 电源读取器与时钟同步模块提供辅助状态。
  4. 控制器更新状态机和当前策略。
  5. 安全检查器根据启用项检查姿态、关节或腿部状态。
  6. 控制器把最终命令写回 SPI，并通过 LCM 发布运行状态。

Viewer、SDK、WebRTC 和外部算法都依赖控制器发布的状态，不能替代对 SPI、IMU 和物理急停的直接检查。

上电前清单¶

  • [ ] 机器人由可靠支架固定，轮子离地或运动区域清空。
  • [ ] 急停和断电路径可由现场人员立即操作。
  • [ ] 两路 SPI、IMU、CAN/BMS 和时钟设备与配置一致。
  • [ ] 供电电压正常，线缆不会进入轮子和关节范围。
  • [ ] 初始模式为 DAMP，速度和姿态命令清零。
  • [ ] 使用的配置、模型和 URDF 已在 MuJoCo 中验证。

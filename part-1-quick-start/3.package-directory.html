1.3 Package Directory¶

yobotics_quad144w/
├── bin/, lib/               # x86_64 controller entry and shared libraries
├── bin_rk3588/, lib_rk3588/ # RK3588/aarch64 controller entry and shared libraries
├── actor_model/             # RL actor/encoder models
├── resources/               # model resources for the hardware Viewer
├── resources_sim/           # MuJoCo simulation resources
├── mujoco_sim/              # simulation program
├── scripts/                 # startup, network, monitoring, and log tools
├── lcm-types/               # LCM definitions and generated code
├── external_algorithms/     # DEVELOPMENT mode examples
├── yobotics_sdk/            # C++ SDK and HTTP examples
├── WebRTC_server/           # video and DataChannel service
├── config.yaml              # hardware configuration
└── config_sim.yaml          # simulation configuration

Two Resource Directories¶

  • resources_sim/robots/quad144w/ is used for MuJoCo simulation.
  • resources/robots/quad144w/ is used by the hardware state Viewer and hardware safety checks.

Both directories contain the Y20W XML, URDF, and mesh files, but they serve different runtime scenarios. When changing paths, always check simulation.mujoco.xml_path and safety_checker.urdf_path in the configuration files together.

Binary Development Package¶

This repository is used as a secondary development package. The controller is started by bin/ybt_ctrl or bin_rk3588/ybt_ctrl. Do not assume the repository contains controller source code or a top-level CMake project; the buildable part is the customer SDK under yobotics_sdk/.
